@MOVE | A | Engage | The matchstick chain that grows by three
@LEAD | A chain of squares is built from matchsticks. The first stage uses 4 matches, the second 7, the third 10. A student claims the fortieth stage will use 120 matches.
@P | It will not. The number grows by 3 at each stage, and the rule that produces the chain is $3n + 1$, not $3n$: the first stage uses 4 matches because of the extra match at the start. At stage 40 the count is $3 \\times 40 + 1 = 121$.
@P | Algebra exists to make that reasoning possible without drawing all forty stages. A **pattern** is described by a **rule**; the rule is written as an **expression**; an unknown in the rule is found by solving an **equation**. Those three moves — describe, express, solve — are what this chapter teaches.

Stage $n$ ; Squares drawn ; Matches used ; Rule $3n + 1$
1 ; 1 ; 4 ; 4
2 ; 2 ; 7 ; 7
3 ; 3 ; 10 ; 10
10 ; 10 ; 31 ; 31
@MINI | Notice and wonder
@LISTU
- Why does the count go up by 3 each time rather than 4?
- Which is easier to extend to stage 100: the drawing or the rule?
- What would a stage 0 mean, and would the rule still give a sensible answer?
- If a chain used 100 matches, how many squares would it have?
@CALLOUT | Keep this question open: when does a pattern become a rule, and what makes a rule trustworthy beyond the cases we have checked?

@SEC | 6.1 | Patterns and rules | Criterion B · i, ii
@LEAD | A sequence of numbers is a pattern; a rule describes it. Two kinds of description matter: how to get from one term to the next, and how to get to any term directly.
@DEF | Sequences and rules
A **sequence** is a list of numbers in order, called **terms**. A **term-to-term rule** says how to get from one term to the next. A **position-to-term rule** gives the term from its position $n$.
For 5, 8, 11, 14, …: the term-to-term rule is “add 3”; the position-to-term rule is $3n + 2$.
@KEY | Why the difference points to the rule
If successive terms differ by a constant $d$, the rule contains $dn$. Subtracting $dn$ from each term then shows what must be added to reach the first term. For 5, 8, 11, 14, … the difference is 3, and $5 - 3 \\times 1 = 2$, so the rule is $3n + 2$.
@TABLE | Two descriptions of the same sequence
Position $n$ ; 1 ; 2 ; 3 ; 4 ; 5
Term ; 5 ; 8 ; 11 ; 14 ; 17
$3n$ ; 3 ; 6 ; 9 ; 12 ; 15
Term $- 3n$ ; 2 ; 2 ; 2 ; 2 ; 2
@METHOD | Finding a position-to-term rule
@LISTO
1. Write the terms in a table with their positions.
2. Find the constant difference $d$ between successive terms.
3. Subtract $dn$ from each term; the constant remainder is the number added to the rule.
4. Check the rule on at least two positions, including one you did not use.
@ERR | Assuming the first term is the multiplier
In the sequence 4, 7, 10, 13, … the first term is 4, but the rule is not $4n$. The constant difference is 3, so the rule is $3n + 1$. The first term is used at the end of the process, not the beginning.

@EX | 6.1.1 | Finding a rule from terms
GIVEN: The sequence 7, 12, 17, 22, …
ASKED: Find the position-to-term rule and the 20th term.
METHOD: Use the constant difference and adjust for the first term.
STEPS:
1. The difference is 5, so the rule contains $5n$.
2. $7 - 5 \\times 1 = 2$, so the rule is $5n + 2$.
3. 20th term: $5 \\times 20 + 2 = 102$.
ANSWER: Rule $5n + 2$; 20th term 102.
CHECK: The 4th term by rule is 22, which matches the sequence.

@EX | 6.1.2 | Using a rule to find a position
GIVEN: A sequence has rule $4n + 3$. One of its terms is 51.
ASKED: Find the position of that term.
METHOD: Form an equation from the rule and solve it.
STEPS:
1. $4n + 3 = 51$.
2. $4n = 48$.
3. $n = 12$.
ANSWER: The 12th term.
CHECK: $4 \\times 12 + 3 = 51$.

@EX | 6.1.3 | A sequence that decreases
GIVEN: The sequence 30, 26, 22, 18, …
ASKED: Find the rule, and state whether the sequence ever reaches 0.
METHOD: Use the constant difference, which is negative.
STEPS:
1. The difference is $-4$, so the rule contains $-4n$.
2. $30 - (-4 \\times 1) = 34$, so the rule is $34 - 4n$.
3. The 8th term is $34 - 32 = 2$ and the 9th is $-2$, so the sequence passes from 2 to $-2$ and never equals 0.
ANSWER: Rule $34 - 4n$; the sequence skips 0 because 34 is not a multiple of 4.
CHECK: The 1st term is $34 - 4 = 30$, and the 4th is $34 - 16 = 18$.

@SEC | 6.2 | Expressions and substitution | Criterion A · i, ii
@LEAD | An expression is a mathematical phrase built from numbers, letters and operations. It has no equals sign: it describes a calculation, and it can be evaluated once the letters are known.
@DEF | Expression, term, coefficient, substitution
An **expression** combines numbers and letters with operations, such as $3x + 5$ or $2(a - 4)$. A **term** is a part separated by + or − signs. The **coefficient** is the number multiplying a letter: in $7y$ the coefficient is 7.
**Substituting** means replacing a letter with a number and calculating the result.
@KEY | Notation that prevents errors
@LISTU
- $3x$ means $3 \\times x$; the multiplication sign is not written.
- $x^{2}$ means $x \\times x$, not $2x$. If $x = 5$, $x^{2} = 25$ but $2x = 10$.
- $\\frac{x}{4}$ means $x \\div 4$.
- Brackets show that the whole bracket is multiplied: $2(x + 3)$ means $2 \\times (x + 3)$.
@METHOD | Substituting into an expression
@LISTO
1. Rewrite the expression with the number in brackets where the letter was.
2. Follow the order of operations: brackets, indices, multiplication and division, then addition and subtraction.
3. Include the units if the expression represents a quantity.
@TABLE | Substituting into $3x^{2} - 2y$
Value of $x$ ; Value of $y$ ; Working ; Result
2 ; 1 ; $3 \\times 4 - 2$ ; 10
3 ; 5 ; $3 \\times 9 - 10$ ; 17
0 ; 4 ; $0 - 8$ ; $-8$
-1 ; 2 ; $3 \\times 1 - 4$ ; $-1$
@ERR | Squaring the coefficient
In $3x^{2}$ with $x = 4$, the square applies only to $x$: $3 \\times 16 = 48$. Writing $(3 \\times 4)^{2} = 144$ squares the 3 as well, which the notation does not say.

@EX | 6.2.1 | Substituting two values
GIVEN: The expression $5a - 2b + 7$.
ASKED: Evaluate it when $a = 4$ and $b = 3$, and when $a = 0$ and $b = 6$.
METHOD: Substitute in brackets and follow the order of operations.
STEPS:
1. $5(4) - 2(3) + 7 = 20 - 6 + 7 = 21$.
2. $5(0) - 2(6) + 7 = 0 - 12 + 7 = -5$.
ANSWER: 21 and $-5$.
CHECK: The first is positive because $5a$ dominates; the second is negative because $-2b$ dominates.

@EX | 6.2.2 | Substituting a negative number
GIVEN: The expression $x^{2} - 3x + 1$.
ASKED: Evaluate it when $x = -2$.
METHOD: Put the negative number in brackets so the signs are visible.
STEPS:
1. $(-2)^{2} - 3(-2) + 1$.
2. $4 + 6 + 1$.
ANSWER: 11.
CHECK: Both the square and the product with $-3$ are positive here, so the result exceeds the value at $x = 2$, which is $4 - 6 + 1 = -1$.
WATCH: $-2^{2}$ without brackets means $-(2^{2}) = -4$. The brackets change the meaning, and they change the answer.

@EX | 6.2.3 | Using an expression in context
GIVEN: A taxi charges 3 units to start and 2 units for each kilometre. The cost for $k$ kilometres is $2k + 3$.
ASKED: Find the cost of an 8 km journey, and the distance travelled for 21 units.
METHOD: Substitute to find the cost; solve an equation to find the distance.
STEPS:
1. $2(8) + 3 = 19$ units.
2. $2k + 3 = 21$, so $2k = 18$ and $k = 9$ km.
ANSWER: 19 units for 8 km; 9 km for 21 units.
CHECK: $2 \\times 9 + 3 = 21$.

@SEC | 6.3 | Simplifying expressions | Criterion A · ii; Criterion C · i
@LEAD | Simplifying collects like terms and removes brackets. It does not change the value of the expression: it changes how the same value is written.
@DEF | Like terms and simplifying
**Like terms** contain exactly the same letters raised to the same powers, such as $4a$ and $-7a$. They can be combined by adding or subtracting their coefficients.
$4a + 3b - a + 2b = 3a + 5b$
Terms with different letters, such as $3a$ and $5b$, cannot be combined into one term.
@KEY | Why collecting works
$4a - a$ means four lots of $a$ minus one lot of $a$, which leaves three lots: $3a$. This is the distributive idea in disguise, and it is why only like terms combine: $3a + 5b$ cannot collapse, because $a$ and $b$ count different things.
@METHOD | Simplifying an expression
@LISTO
1. Identify the like terms, including their signs.
2. Collect them, keeping the sign in front of each term with it.
3. Expand any brackets first, then collect.
4. Check by substituting a value into the original and the simplified form; the results must agree.
@TABLE | Expanding brackets
Expression ; Expanded ; Why
$3(x + 4)$ ; $3x + 12$ ; every term in the bracket is multiplied by 3
$5(2a - 1)$ ; $10a - 5$ ; the 5 multiplies both terms
$2(x + 3) + 4(x - 1)$ ; $6x + 2$ ; expand, then collect like terms
$-3(y + 2)$ ; $-3y - 6$ ; a negative multiplier changes both signs
@ERR | Sign errors when collecting
In $7x - 3 - 2x + 8$, the correct collection is $5x + 5$. Treating the minus as belonging to the 3 but not the 2 gives wrong answers. Circling each sign with its term prevents the error.

@EX | 6.3.1 | Collecting like terms
GIVEN: $8a + 5 - 3a + 2b - 7$.
ASKED: Simplify.
METHOD: Group like terms and combine coefficients.
STEPS:
1. $a$ terms: $8a - 3a = 5a$.
2. $b$ terms: $2b$.
3. Numbers: $5 - 7 = -2$.
ANSWER: $5a + 2b - 2$.
CHECK: At $a = 1, b = 1$: original $8 + 5 - 3 + 2 - 7 = 5$; simplified $5 + 2 - 2 = 5$.

@EX | 6.3.2 | Expanding and simplifying
GIVEN: $4(2x + 3) - 2(x - 5)$.
ASKED: Expand and simplify.
METHOD: Multiply every term in each bracket, then collect.
STEPS:
1. $4(2x + 3) = 8x + 12$.
2. $-2(x - 5) = -2x + 10$.
3. $8x + 12 - 2x + 10 = 6x + 22$.
ANSWER: $6x + 22$.
CHECK: At $x = 2$: original $4(7) - 2(-3) = 28 + 6 = 34$; simplified $12 + 22 = 34$.
WATCH: The second bracket is multiplied by $-2$, so $-2 \\times -5 = +10$. Losing that sign is the commonest error in this topic.

@EX | 6.3.3 | Forming and simplifying from a context
GIVEN: A rectangle has width $w$ cm and length 3 cm more than twice the width.
ASKED: Write and simplify an expression for the perimeter.
METHOD: Write each side, then add.
STEPS:
1. Width $w$; length $2w + 3$.
2. Perimeter $= 2w + 2(2w + 3)$.
3. Expand: $2w + 4w + 6 = 6w + 6$.
ANSWER: $6w + 6$ cm.
CHECK: If $w = 4$, the rectangle is 4 by 11, perimeter 30; the expression gives 30.

@SEC | 6.4 | Solving linear equations | Criterion A · iii; Criterion C · iii
@LEAD | An equation states that two expressions are equal. Solving it means finding the value of the letter that makes the statement true, and inverse operations are the tool.
@FIG | c06_balance
@DEF | Equation and solution
An **equation** contains an equals sign. A **solution** is a value of the letter that makes the equation true. Equations with the letter appearing only to the first power are **linear**.
$3x + 4 = 19$ has the solution $x = 5$, because $3 \\times 5 + 4 = 19$.
@KEY | The balance idea
An equation is a balance. Whatever is done to one side must be done to the other, or the balance is destroyed. Solving means undoing the operations in reverse order: if the expression multiplied by 3 and then added 4, undo the adding first, then the multiplying.
@FIG | c06_steps
@METHOD | Solving a linear equation
@LISTO
1. Simplify each side if necessary.
2. Undo addition or subtraction first, then multiplication or division.
3. Keep the equation balanced by doing the same operation to both sides.
4. Check by substituting the solution into the original equation.
@TABLE | Two-step and bracket equations
Equation ; First step ; Second step ; Solution
$2x + 7 = 15$ ; subtract 7 ; divide by 2 ; $x = 4$
$5(x - 2) = 20$ ; divide by 5 ; add 2 ; $x = 6$
$\\frac{x}{4} + 3 = 7$ ; subtract 3 ; multiply by 4 ; $x = 16$
$9 - 2x = 1$ ; subtract 9 ; divide by $-2$ ; $x = 4$
@ERR | Working on one side only
Subtracting 4 from the left of $3x + 4 = 19$ without subtracting from the right changes the equation into a false statement. A useful habit is to write the operation beside the equation, as in the figure, so the balance is visible.

@EX | 6.4.1 | A two-step equation
GIVEN: $4x - 7 = 21$.
ASKED: Solve for $x$.
METHOD: Undo the subtraction, then the multiplication.
STEPS:
1. Add 7 to both sides: $4x = 28$.
2. Divide both sides by 4: $x = 7$.
ANSWER: $x = 7$.
CHECK: $4 \\times 7 - 7 = 21$.

@EX | 6.4.2 | An equation with brackets
GIVEN: $3(x + 4) = 27$.
ASKED: Solve for $x$, using two different first steps.
METHOD: Either divide by 3 first, or expand the bracket.
STEPS:
1. Dividing first: $x + 4 = 9$, so $x = 5$.
2. Expanding first: $3x + 12 = 27$, so $3x = 15$ and $x = 5$.
ANSWER: $x = 5$.
CHECK: $3(5 + 4) = 27$.
WATCH: Both routes are valid; choosing one and finishing it is better than starting both.

@EX | 6.4.3 | An equation with the letter on both sides
GIVEN: $5x - 3 = 2x + 12$.
ASKED: Solve for $x$.
METHOD: Collect the letter terms on one side and the numbers on the other.
STEPS:
1. Subtract $2x$ from both sides: $3x - 3 = 12$.
2. Add 3 to both sides: $3x = 15$.
3. Divide by 3: $x = 5$.
ANSWER: $x = 5$.
CHECK: Left $= 25 - 3 = 22$; right $= 10 + 12 = 22$.

@SEC | 6.5 | Forming and using equations | Criterion D · i, ii
@LEAD | The difficult part of an applied problem is rarely the solving. It is translating the words into an equation, which requires naming the unknown and stating the relationship it satisfies.
@METHOD | Translating words into equations
@LISTO
1. Name the unknown: “let $x$ be the number of …”.
2. Write the relationship as an equation, checking that both sides measure the same kind of quantity.
3. Solve, then answer the question that was asked, with units.
4. Check that the answer is sensible in the context, not merely arithmetically correct.
@TABLE | Words and their equations
Statement ; Equation
A number increased by 8 is 21. ; $x + 8 = 21$
Three times a number, less 5, is 16. ; $3x - 5 = 16$
Two consecutive numbers add to 35. ; $x + (x + 1) = 35$
A taxi costs 3 plus 2 per km; a journey costs 21. ; $2k + 3 = 21$
The perimeter of a square is 36. ; $4s = 36$
@ERR | Answering the wrong question
“A number is tripled and then 4 is added, giving 25” leads to $3x + 4 = 25$ and $x = 7$. If the question then asks for the value after tripling, the answer is 21, not 7. Always return to the question at the end.

@EX | 6.5.1 | A number problem
GIVEN: Three consecutive whole numbers have a sum of 72.
ASKED: Find the numbers.
METHOD: Name the middle number $x$ so the others are $x - 1$ and $x + 1$.
STEPS:
1. $(x - 1) + x + (x + 1) = 72$.
2. $3x = 72$.
3. $x = 24$, so the numbers are 23, 24 and 25.
ANSWER: 23, 24, 25.
CHECK: $23 + 24 + 25 = 72$.

@EX | 6.5.2 | A geometry problem
GIVEN: A rectangle is twice as long as it is wide, and its perimeter is 54 cm.
ASKED: Find the dimensions.
METHOD: Name the width $w$, write the perimeter, and solve.
STEPS:
1. Width $w$, length $2w$.
2. Perimeter: $2w + 2(2w) = 6w$.
3. $6w = 54$, so $w = 9$ and the length is 18.
ANSWER: 9 cm by 18 cm.
CHECK: $2(9) + 2(18) = 54$.

@EX | 6.5.3 | A comparison problem
GIVEN: A school hires a hall for a fixed 120 units plus 3 units per student. A second hall charges 6 units per student with no fixed charge.
ASKED: For how many students do the two halls cost the same?
METHOD: Write both costs as expressions and set them equal.
STEPS:
1. First hall: $3n + 120$; second: $6n$.
2. $3n + 120 = 6n$.
3. $120 = 3n$, so $n = 40$.
ANSWER: 40 students, when each costs 240 units.
CHECK: First hall $3(40) + 120 = 240$; second $6(40) = 240$.
WATCH: Forming the equation as $6n + 120 = 3n$ inverts the two halls and gives a negative answer, which is a signal that the expressions have been swapped.

@MOVE | G | Reflect and consolidate | Summary, vocabulary, misconceptions and review
@SEC | Review | Consolidating Chapter 6 | Criterion A · i, ii, iii
@H2 | What this chapter established
@LISTU
- A sequence can be described by a term-to-term rule or by a position-to-term rule.
- A constant difference $d$ means the rule contains $dn$; the remainder fixes the constant.
- Expressions are evaluated by substitution, following the order of operations.
- Like terms can be collected; brackets are removed by multiplying every term inside.
- Linear equations are solved by inverse operations applied to both sides.
- Word problems become equations by naming the unknown and stating the relationship.
@H2 | Essential vocabulary
@TABLE | Vocabulary for Chapter 6
Term ; Meaning in this course
Sequence ; A list of numbers in order, called terms.
Term ; One number or element of a sequence.
Position-to-term rule ; A rule giving the term from its position $n$.
Expression ; Numbers and letters combined with operations, without an equals sign.
Coefficient ; The number multiplying a letter.
Substitution ; Replacing letters with numbers.
Like terms ; Terms with identical letters and powers.
Equation ; A statement that two expressions are equal.
Solution ; A value that makes an equation true.
Linear ; The letter appears only to the first power.
@H2 | Common misconceptions
@TABLE | Misconception, correction and evidence
Misconception ; Correction ; Evidence
“$x^{2}$ means $2x$.” ; It means $x \\times x$. ; $6^{2} = 36$, $2 \\times 6 = 12$
“The rule is the first term times $n$.” ; Find the difference first. ; 4, 7, 10 gives $3n + 1$
“$3a + 4b = 7ab$.” ; Unlike terms do not combine. ; $a$ and $b$ count different quantities
“Subtract from one side.” ; Both sides must change. ; $3x + 4 = 19$
“$-2(x - 5) = -2x - 10$.” ; Both signs change. ; $-2 \\times -5 = +10$
