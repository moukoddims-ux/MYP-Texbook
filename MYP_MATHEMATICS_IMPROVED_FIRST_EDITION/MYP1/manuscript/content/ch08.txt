@MOVE | A | Engage | Who is in the group?
@LEAD | A club advertises two activities: chess and football. Of 40 members, 22 play chess and 25 play football. A member reads the notice and says “that is 47 members, but the club only has 40 — the numbers must be wrong.”
@P | The numbers are not wrong. Some members do both activities, and those members are counted in both figures. The overlap is the missing information: $22 + 25 - 40 = 7$ members play both. This is the arithmetic of sets, and it explains a great many surveys, registers and reports.
@P | Sets are also how mathematics classifies. A set is defined by a rule that decides membership without ambiguity, which is exactly what a fair classification needs: no member left out, no member counted twice, and the same decision every time.

@SEC | 8.1 | Sets and set notation | Criterion A · i, ii
@LEAD | A set is a collection defined precisely enough that membership is never in doubt. The notation exists to make that precision visible.
@DEF | Sets and their notation
A **set** is a well-defined collection of objects, called its **elements**. Sets are named with capital letters and listed in braces: $A = \\{2, 4, 6, 8\\}$.
@LISTU
- $x \\in A$ means $x$ is an element of $A$; $x \\notin A$ means it is not.
- The **universal set** $\\mathcal{U}$ contains everything under discussion.
- The **empty set** $\\{\\}$ or $\\emptyset$ has no elements.
- The **cardinality** $n(A)$ is the number of elements in $A$.
@KEY | Two ways to describe the same set
**Listing** (roster method) names each element: $B = \\{3, 6, 9, 12\\}$.
**Rule** (set-builder method) states the condition: $B = \\{x : x \\text{ is a multiple of } 3 \\text{ and } 0 < x < 15\\}$.
The listing is easier to read; the rule is easier to extend and to test. Both describe exactly the same set, and neither leaves membership in doubt — which is the whole point.
@TABLE | Sets described by rules
Set ; Rule ; Listed
Even numbers below 10 ; $\\{x : x \\text{ even}, 0 < x < 10\\}$ ; $\\{2, 4, 6, 8\\}$
Factors of 12 ; $\\{x : x \\text{ divides } 12\\}$ ; $\\{1, 2, 3, 4, 6, 12\\}$
Prime numbers below 20 ; $\\{x : x \\text{ prime}, x < 20\\}$ ; $\\{2, 3, 5, 7, 11, 13, 17, 19\\}$
Whole numbers between 4 and 5 ; $\\{x : 4 < x < 5, x \\text{ whole}\\}$ ; $\\emptyset$
@METHOD | Working with sets
@LISTO
1. Decide the universal set first: “multiples of 3” means nothing until the range is known.
2. List elements without repetition; order does not matter in a set.
3. Use a rule when the set is large or infinite, and a list when it is small.
4. Check the cardinality by counting the listed elements.
@ERR | A rule that does not decide
“The set of tall students” is not a set in the mathematical sense, because “tall” is not defined precisely enough to decide every case. “Students taller than 1.70 m” is a set. Precision, not subject matter, is what makes a collection a set.

@EX | 8.1.1 | Listing and describing
GIVEN: The set $A = \\{x : x \\text{ is a factor of } 18\\}$ with $\\mathcal{U} = \\{1, 2, 3, \\dots, 20\\}$.
ASKED: List the elements of $A$ and state $n(A)$.
METHOD: Test each whole number up to 18.
STEPS:
1. Factors: 1, 2, 3, 6, 9, 18.
2. Count: six elements.
ANSWER: $A = \\{1, 2, 3, 6, 9, 18\\}$ and $n(A) = 6$.
CHECK: Each listed number divides 18 exactly; no other number below 20 does.

@EX | 8.1.2 | Membership and the empty set
GIVEN: $B = \\{x : x \\text{ is an even prime number}\\}$ and $C = \\{x : x \\text{ is a multiple of } 4, 10 < x < 12\\}$.
ASKED: Describe each set.
METHOD: Test the definition against the possible values.
STEPS:
1. The only even prime is 2, so $B = \\{2\\}$.
2. There is no multiple of 4 strictly between 10 and 12, so $C = \\emptyset$.
ANSWER: $B$ has one element; $C$ is empty.
CHECK: $n(B) = 1$ and $n(C) = 0$.

@EX | 8.1.3 | Sets in a school context

@SEC | 8.2 | Subsets, union, intersection and complement | Criterion A · ii; Criterion C · i
@LEAD | Four operations describe how sets relate: being inside, combining, overlapping and excluding. Each has a symbol, and each has a picture in a Venn diagram.
@DEF | Set operations
@LISTU
- **Subset:** $A \\subseteq B$ means every element of $A$ is in $B$.
- **Union:** $A \\cup B$ contains everything in $A$ or in $B$ or in both.
- **Intersection:** $A \\cap B$ contains only what is in both.
- **Complement:** $A'$ contains everything in $\\mathcal{U}$ that is not in $A$.
@KEY | The rule that links them
For any two sets, $n(A \\cup B) = n(A) + n(B) - n(A \\cap B)$.
The subtraction corrects for double counting: elements in both sets appear twice in $n(A) + n(B)$ and should appear once in the union. This single formula answers most survey questions.
@TABLE | Operations on $A = \\{1, 2, 3, 4\\}$ and $B = \\{3, 4, 5, 6\\}$
Operation ; Result ; Cardinality
$A \\cap B$ ; $\\{3, 4\\}$ ; 2
$A \\cup B$ ; $\\{1, 2, 3, 4, 5, 6\\}$ ; 6
$A'$ with $\\mathcal{U} = \\{1, \\dots, 8\\}$ ; $\\{5, 6, 7, 8\\}$ ; 4
$A \\cap B'$ ; $\\{1, 2\\}$ ; 2
@ERR | Adding without correcting
$n(A) + n(B)$ counts the overlap twice. A survey in which 18 like tea, 14 like coffee and 6 like both gives $18 + 14 - 6 = 26$ who like at least one, not 32. If the group has 30 members, 4 like neither — a figure that is easy to forget and easy to check.

@EX | 8.2.1 | Finding union and intersection
GIVEN: $A = \\{2, 4, 6, 8, 10\\}$ and $B = \\{4, 8, 12\\}$.
ASKED: Find $A \\cap B$, $A \\cup B$ and their cardinalities.
METHOD: Compare the lists element by element.
STEPS:
1. Common elements: 4 and 8, so $A \\cap B = \\{4, 8\\}$ and $n(A \\cap B) = 2$.
2. All elements: 2, 4, 6, 8, 10, 12, so $n(A \\cup B) = 6$.
ANSWER: $\\{4, 8\\}$ and $\\{2, 4, 6, 8, 10, 12\\}$.
CHECK: $5 + 3 - 2 = 6$, which matches the union count.

@EX | 8.2.2 | A survey with neither group
GIVEN: In a class of 32, 20 study biology and 15 study chemistry; 8 study both.
ASKED: Find how many study at least one, and how many study neither.
METHOD: Use the union formula, then subtract from the total.
STEPS:
1. At least one: $20 + 15 - 8 = 27$.
2. Neither: $32 - 27 = 5$.
ANSWER: 27 study at least one; 5 study neither.
CHECK: The four regions are $12 + 8 + 7 + 5 = 32$.

@EX | 8.2.3 | Using the complement
GIVEN: $\\mathcal{U} = \\{1, 2, \\dots, 20\\}$, $A = \\{$multiples of 3$\\}$ and $B = \\{$multiples of 5$\\}$.
ASKED: Find $A \\cap B$, $A \\cup B$ and $n((A \\cup B)')$.
METHOD: List both sets, then apply the operations.
STEPS:
1. $A = \\{3, 6, 9, 12, 15, 18\\}$ and $B = \\{5, 10, 15, 20\\}$.
2. $A \\cap B = \\{15\\}$.
3. $A \\cup B = \\{3, 5, 6, 9, 10, 12, 15, 18, 20\\}$, with 9 elements.
4. Complement: $20 - 9 = 11$.
ANSWER: $\\{15\\}$; nine elements; 11 elements outside.
CHECK: $6 + 4 - 1 = 9$.
WATCH: A number that is in both sets must appear once in the union. Listing it twice inflates the count.

@SEC | 8.3 | Venn diagrams and survey problems | Criterion D · i, ii, iv
@LEAD | A two-set Venn diagram has four regions, and every survey question about two groups can be solved by filling them in the right order.
@FIG | c08_survey
@METHOD | Solving a survey problem
@LISTO
1. Draw the rectangle for $\\mathcal{U}$ and two overlapping circles.
2. Put the number for “both” in the overlap first.
3. Subtract to fill “only $A$” and “only $B$”.
4. Add the three regions and subtract from the total to find “neither”.
5. Check that all four numbers add to the total.
@KEY | Why the overlap comes first
The overlap is the only region that belongs to both sets, so every other region depends on it. Filling it first means the other numbers are found by subtraction, with no simultaneous unknowns. Starting anywhere else produces answers that do not add up.
@TABLE | A worked survey
Information ; Region ; Count
50 students in total ; outside the circles ; 
23 walk ; $A$ only $+$ both ; 
21 cycle ; $B$ only $+$ both ; 
9 both ; overlap ; 9
$A$ only ; $23 - 9$ ; 14
$B$ only ; $21 - 9$ ; 12
Neither ; $50 - (14 + 9 + 12)$ ; 15
@ERR | Forgetting the rectangle
The number who belong to neither set has no circle to live in, and it is easy to leave it out. Always draw the rectangle, and always check that the regions add to the total.

@EX | 8.3.1 | Filling a Venn diagram
GIVEN: In a class of 36, 19 play an instrument and 17 play a sport; 6 do both.
ASKED: Draw a Venn diagram and state how many do neither.
METHOD: Overlap first, then subtract, then check.
STEPS:
1. Both: 6.
2. Instrument only: $19 - 6 = 13$.
3. Sport only: $17 - 6 = 11$.
4. Neither: $36 - (13 + 6 + 11) = 6$.
ANSWER: 6 students do neither.
CHECK: $13 + 6 + 11 + 6 = 36$.

@EX | 8.3.2 | Working backwards from the diagram
GIVEN: A diagram shows 12 in $A$ only, 5 in both, 9 in $B$ only and 4 outside both.
ASKED: Find $n(A)$, $n(B)$, $n(A \\cup B)$ and the total.
METHOD: Read each region and combine.
STEPS:
1. $n(A) = 12 + 5 = 17$.
2. $n(B) = 9 + 5 = 14$.
3. $n(A \\cup B) = 12 + 5 + 9 = 26$.
4. Total: $26 + 4 = 30$.
ANSWER: 17, 14, 26, 30.
CHECK: $17 + 14 - 5 = 26$.

@EX | 8.3.3 | A problem with the group size missing
GIVEN: 40 people were asked about two newspapers. 24 read paper $A$, 18 read paper $B$ and 7 read both.
ASKED: Find how many read exactly one paper, and how many read neither.
METHOD: Fill the regions; the total is given, so “neither” follows.
STEPS:
1. $A$ only: $24 - 7 = 17$.
2. $B$ only: $18 - 7 = 11$.
3. Exactly one: $17 + 11 = 28$.
4. Neither: $40 - (28 + 7) = 5$.
ANSWER: 28 read exactly one; 5 read neither.
CHECK: $17 + 7 + 11 + 5 = 40$.
WATCH: “Exactly one” excludes the overlap while “at least one” includes it. Reading the question carefully is part of the mathematics.

@SEC | 8.4 | Classification and fair decisions | Criterion C · iii; Criterion D · iii, v
@LEAD | To classify is to divide a group into categories using a rule. A classification is mathematically sound when every member lands in exactly one category and the rule gives the same answer every time.
@FIG | c08_tree
@DEF | Classification
A **classification** assigns every member of a set to exactly one of several categories. The categories are **mutually exclusive** (no member belongs to two) and **exhaustive** (no member is left out).
A classification tree makes the decisions visible: each branch applies one rule, and the branches at each stage cover every possibility.
@KEY | The two tests for a fair classification
@LISTU
- **Mutually exclusive:** check that no object satisfies two categories. If “even” and “prime” were categories, 2 would belong to both.
- **Exhaustive:** check that every object fits somewhere. “Multiples of 4” and “not multiples of 4” is exhaustive; “multiples of 4” and “odd numbers” is not, because 6 fits neither.
@TABLE | Classifications tested
Categories ; Mutually exclusive? ; Exhaustive? ; Verdict
Even, odd ; yes ; yes ; sound
Even, prime ; no (2 is both) ; no (9 fits neither) ; unsound
Multiple of 4, not a multiple of 4 ; yes ; yes ; sound
Negative, zero, positive ; yes ; yes for integers ; sound
Pass, fail, absent ; yes if defined once ; yes ; sound if the rules are stated
@METHOD | Building a classification
@LISTO
1. Decide the universal set: the group being classified.
2. Choose a rule that every member either satisfies or does not.
3. Split first by one rule, then by another within each branch.
4. Test for overlaps and gaps with awkward cases, especially boundary values.
5. State the rule precisely enough that two people would decide the same way.
@ERR | Categories that overlap in practice
“Students who take the bus” and “students who walk” look exclusive until a student does both on different days of the week. The categories were defined by mode of travel without a time frame. Precision in the rule, not confidence in the answer, is what prevents this.

@EX | 8.4.1 | Testing a classification
GIVEN: A class is divided into “has a pet” and “has a brother”.
ASKED: Decide whether the classification is sound.
METHOD: Test for overlap and for gaps.
STEPS:
1. Overlap: a student can have both a pet and a brother, so the categories are not mutually exclusive.
2. Gap: a student with neither belongs to no category, so the categories are not exhaustive.
ANSWER: Unsound; the categories overlap and leave a gap.
CHECK: Sketching the two circles shows a two-region overlap and an outside region — the classification is not a division into separate parts.

@EX | 8.4.2 | A sound classification
GIVEN: Whole numbers from 1 to 30.
ASKED: Classify them so that each number falls in exactly one category, using factors.
METHOD: Choose rules that are complementary at each stage.
STEPS:
1. First split: prime or composite — but 1 is neither, so the rule must be “prime”, “composite”, “neither”.
2. Test boundary cases: 1 (neither), 2 (prime), 4 (composite).
3. Count the categories: 10 primes, 19 composites, 1 neither; total 30.
ANSWER: Prime, composite and neither is an exhaustive, mutually exclusive classification for whole numbers above 0.
CHECK: $10 + 19 + 1 = 30$.

@EX | 8.4.3 | Classification and fairness in a decision
GIVEN: A school gives a prize to “the best all-round student”, judged on mathematics, sport and service.
ASKED: Suggest how to make the decision fair using classification and counting.
METHOD: Replace a vague category with stated criteria and measurable evidence.
STEPS:
1. Define each criterion precisely, for example “service: at least 10 hours recorded”.
2. Decide whether a student must meet all criteria or a stated number of them.
3. Count how many students meet each combination, and check that no one is excluded by an unstated rule.
ANSWER: A fair scheme states the criteria, applies them to everyone, and shows the counts for each combination of criteria.
CHECK: If the criteria leave a student unclassified, the scheme is not exhaustive and must be revised.
WATCH: A criterion that depends on opinion cannot be applied consistently. Mathematics can organise a decision, but it cannot make a vague rule precise on its own.

@SEC | 8.5 | Number sets and the real line | Criterion A · i, ii; Criterion C · ii, iii
@LEAD | Numbers come in families that fit inside one another like nested sets. Writing those families down, and testing a number to see where it belongs, is a good use of everything this chapter has built.
@DEF | The number sets
$\mathbb{N}$ — the **natural numbers** $1, 2, 3, \dots$ (sometimes including 0).
$\mathbb{Z}$ — the **integers**: all whole numbers, positive, negative and zero.
$\mathbb{Q}$ — the **rational numbers**: every number that can be written as $\frac{a}{b}$ with integers $a$ and $b$ and $b \ne 0$. This includes fractions, terminating decimals and recurring decimals.
**Irrational numbers** cannot be written as a fraction of two integers: $\sqrt{2}$, $\pi$ and $0.1010010001\dots$ are examples.
$\mathbb{R}$ — the **real numbers**: every rational and every irrational number, which is to say every point on the number line.
@KEY | The sets fit inside one another
Every natural number is an integer, every integer is rational, and every rational number is real:
$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$
So the number $-3$ is in $\mathbb{Z}$, $\mathbb{Q}$ and $\mathbb{R}$ but not in $\mathbb{N}$. A number that is not rational is irrational, and it is still real.
@TABLE | Testing where numbers belong
Number ; $\mathbb{N}$ ; $\mathbb{Z}$ ; $\mathbb{Q}$ ; $\mathbb{R}$ ; Reason
7 ; yes ; yes ; yes ; yes ; a whole number
−4 ; no ; yes ; yes ; yes ; negative
$\frac{2}{3}$ ; no ; no ; yes ; yes ; a fraction of integers
$0.\overline{6}$ ; no ; no ; yes ; yes ; recurring decimals are fractions: $\frac{2}{3}$
$\sqrt{9}$ ; yes ; yes ; yes ; yes ; equals 3, so it is an integer
$\sqrt{2}$ ; no ; no ; no ; yes ; cannot be written as a fraction
$\pi$ ; no ; no ; no ; yes ; irrational
@DEF | Decimals on the number line
Every terminating or recurring decimal has an exact position on the number line. Between any two rational numbers there is another rational number — take their average — so the rationals are **dense**. The irrationals fill the remaining points, and together with the rationals they cover the whole line.
@ERR | “A square root is always irrational”
$\sqrt{9} = 3$ and $\sqrt{0.25} = 0.5$ are rational. A square root is irrational only when the number under it is not a perfect square of a rational. Simplify first, then classify.

@EX | 8.5.1 | Classifying numbers
GIVEN: $-7$, $\frac{5}{8}$, $\sqrt{16}$, $0.4\dot{1}$, $\sqrt{5}$.
ASKED: Place each in the smallest set it belongs to.
METHOD: Test in order: natural, integer, rational, otherwise irrational.
STEPS:
1. $-7$ is an integer but not natural: $\mathbb{Z}$.
2. $\frac{5}{8}$ is a fraction of integers: $\mathbb{Q}$.
3. $\sqrt{16} = 4$, a natural number: $\mathbb{N}$.
4. $0.4\dot{1}$ recurs, and $0.4\dot{1} = \frac{41}{99}$: $\mathbb{Q}$.
5. $\sqrt{5} \approx 2.236$ does not terminate or repeat: irrational.
ANSWER: $\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{N}$, $\mathbb{Q}$ and irrational respectively.
CHECK: Each answer is the smallest set containing the number, and every one of them is also real.

@EX | 8.5.2 | Placing irrationals on the line
GIVEN: $\sqrt{2}$ and $\pi$.
ASKED: Give each to two decimal places and place it between two consecutive integers.
METHOD: Estimate with perfect squares, then refine.
STEPS:
1. $1^{2} = 1$ and $2^{2} = 4$, so $1 < \sqrt{2} < 2$.
2. $1.4^{2} = 1.96$ and $1.5^{2} = 2.25$, so $1.4 < \sqrt{2} < 1.5$, giving $\sqrt{2} \approx 1.41$.
3. $3 < \pi < 4$, and $\pi \approx 3.14$.
ANSWER: $\sqrt{2} \approx 1.41$ between 1 and 2; $\pi \approx 3.14$ between 3 and 4.
CHECK: Squaring the approximation 1.41 gives 1.9881, close to 2.

@EX | 8.5.3 | Sets within a universal set
GIVEN: $\mathcal{U} = \{$whole numbers from 1 to 20$\}$, $A = \{$multiples of 3$\}$, $B = \{$perfect squares$\}$.
ASKED: List $A$, $B$, $A \cap B$ and $A \cup B$, and state $n(A')$.
METHOD: List first, then combine.
STEPS:
1. $A = \{3, 6, 9, 12, 15, 18\}$ and $B = \{1, 4, 9, 16\}$.
2. $A \cap B = \{9\}$ and $A \cup B = \{1, 3, 4, 6, 9, 12, 15, 16, 18\}$.
3. $n(A \cup B) = 9$, so $n(A') = 20 - 6 = 14$.
ANSWER: as listed; $n(A') = 14$.
CHECK: $n(A \cup B) = n(A) + n(B) - n(A \cap B) = 6 + 4 - 1 = 9$.

@MOVE | G | Reflect and consolidate | Summary, vocabulary, misconceptions and review
@SEC | Review | Consolidating Chapter 8 | Criterion A · i, ii, iii
@H2 | What this chapter established
@LISTU
- A set is a well-defined collection; membership must be decidable for every object.
- Sets can be described by listing or by a rule, and the two descriptions can be equivalent.
- Union, intersection and complement have symbols and meanings that mirror the Venn diagram regions.
- $n(A \\cup B) = n(A) + n(B) - n(A \\cap B)$ corrects for double counting.
- Survey problems are solved by filling the overlap first, then subtracting.
- A sound classification is mutually exclusive and exhaustive, and its rules are stated precisely.
@H2 | Essential vocabulary
@TABLE | Vocabulary for Chapter 8
Term | Meaning in this course
Set | A well-defined collection of objects.
Element | A member of a set.
Universal set | The set of everything under discussion.
Empty set | A set with no elements.
Subset | A set all of whose elements belong to another set.
Union | Everything in either set or both.
Intersection | The elements common to both sets.
Complement | Everything in the universal set but not in the set.
Mutually exclusive | Categories with no member in common.
Exhaustive | Categories that cover every member.
@H2 | Common misconceptions
@TABLE | Misconception, correction and evidence
Misconception ; Correction ; Evidence
“Union means add the two sizes.” ; Subtract the overlap. ; $6 + 4 - 1 = 9$
“$\\emptyset$ and $\\{0\\}$ are the same.” ; One has no elements. ; $n(\\emptyset) = 0$, $n(\\{0\\}) = 1$
“Everything outside $A$ is empty.” ; The complement may be large. ; half the universal set
“Any two categories classify.” ; They must not overlap or leave gaps. ; “even” and “prime”
“The overlap can be as large as we like.” ; It cannot exceed the smaller set. ; $n(A \\cap B) \\le n(A)$
